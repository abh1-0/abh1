Welcome to my personal portfolio and engineering blog.

For years, I've focused on building software that prioritizes performance, visual restraint, and structural clarity. Modern software development often gets bogged down in heavy abstractions and unnecessary JS bundles. My engineering philosophy centres around high-velocity interfaces that load near-instantly and feel effortless to interact with.

## Core Focus Areas

- **Full-Stack Systems.** High-performance web applications built using Astro, TypeScript, Next.js, and WebAssembly.
- **Developer Experience.** Designing tools, component systems, and visual canvas interfaces that streamline developer workflows.
- **Low-Latency Architecture.** Sub-16ms DOM rendering, optimized memory usage, and zero-runtime CSS tokens.

Every project showcased here represents real, hands-on implementation. Check out my [Work](/work) page for live interactive demos and open-source code repositories.
