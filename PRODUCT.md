## Platform

web

## Stack

delegated: Astro + Tailwind CSS, static output. Content-led personal engineering portfolio + markdown technical blog with interactive client islands for filtering and modal previews. Near-zero runtime JS footprint, fast page loads, and complete static hosting portability.

## Users

1. **Tech leads, recruiters & engineering hiring managers** — evaluating abh1 for senior software engineering, full-stack, or systems roles. Demands clear visual evidence, clean codebase architecture, and demonstrated technical breadth.
2. **Developers & open-source community** — exploring web apps, developer tools, utility software, and technical write-ups.

## Product Purpose

Personal portfolio and technical blog for **abh1** (`abh1.xyz`). Demonstrates expertise in full-stack web applications, developer tooling, high-performance systems software, and open-source contributions. Combines high-impact project showcases with rich preview imagery and in-depth engineering writing.

## Positioning

Elite developer portfolio built with understated, modern dark aesthetics (Linear/Vercel standard). Features real primary-source project evidence, bespoke visual mockups, interactive filterable work showcases, technical skill breakdowns, and first-person engineering articles.

## Operating Context

- Curated project data layer (`src/data/projects.ts`) enriched with generated visual screenshots, tech badges, metrics, and live/source links.
- GitHub API integration (`src/lib/github.ts`) with hardcoded fallbacks and strict filtering (excludes unwanted repos such as `redirect`, `gesture synth`).
- Domain: `abh1.xyz` with canonical URLs, schema tags, Open Graph cards, and RSS feed.
- Handles: GitHub (`abh1-0`), X, LinkedIn, Telegram, Instagram, contact@abh1.xyz.

## Capabilities and Constraints

- High visual craft bar adhering strictly to Impeccable design guidelines: crisp typography (Geist + Geist Mono), restrained near-black ground (`#09090b`), glassmorphism accents, 1px subtle borders, smooth micro-interactions.
- Blacklisted repositories: `redirect`, `gesture synth` (and variants) are explicitly excluded across all views.
- Every featured project includes high-resolution preview images.

## Product Principles

1. **Show visually, prove technically** — project cards lead with crisp preview images and technical specs.
2. **Restrained elegance** — dark developer aesthetic with high typographic precision, seamless motion, zero unnecessary clutter.
3. **Impeccable craft** — flawless responsiveness, accessible interactive elements, zero placeholders, strict dark mode palette.
